Detailed Description

Simple Build Info library

Library can be used only with GCC toolchain. Build info is placed inside sBuildInfo section if SBI_NO_FIX is not defined during compile/build. Define SBI_NO_FIX and build info will not be placed at fixed location in flash memory. Set maximum length of build info by providing SBI_NAME_LEN, SBI_VER_LEN, SBI_HW_LEN and SBI_FLAGS_LEN defines during build. Default length for info is 16 chars(10 for build flags). Build flags example: DFT

  • D for build with debug prints.
  • F for build with enabled FPU.
  • T for build with trace log system.
